# Laboratorio de hallazgos

«Un hallazgo defendible» amplía la práctica con evidencias y un informe descargable. Usa una política interna ficticia (POL-BCP-01); no atribuye a ISO una obligación inventada.

La semilla produce una de tres situaciones: recuperación fuera de RTO, pérdida de datos fuera de RPO, o datos insuficientes para concluir sobre RPO. Los plazos varían de forma determinista. Registrar la semilla y versión permite discutir exactamente el mismo caso.

La rúbrica comprueba identificación, cruce de evidencias/criterio, clasificación prudente y acción orientada al problema. La longitud de los textos solo comprueba que se han completado. No evalúa su calidad semántica, no decide la gravedad de una no conformidad ni concede credenciales.

El revisor debe valorar si el hallazgo cita datos concretos, distingue criterio de evidencia, evita conclusiones sin soporte y propone una comprobación de eficacia medible. Otras soluciones justificadas pueden ser válidas aunque no coincidan con las opciones de la práctica.

El borrador se guarda con el progreso y el informe se exporta como Markdown sin el nombre del perfil. Para una sesión nueva o un cambio de semilla, descargar antes el informe anterior. El historial de variantes se conserva mediante esos informes, no como una colección ilimitada en el navegador.
